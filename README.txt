KLINAYA Mobile v0.2 — iPhone-ready PWA package.

IMPORTANT: This ZIP is a WEBSITE SOURCE PACKAGE, not an iPhone install file. It must be hosted on an HTTPS website for Safari Add to Home Screen and offline caching.

Easiest deployment with GitHub Pages:
1. Create a new PUBLIC GitHub repository (e.g. klinarya-mobile-demo). Do not upload any student data.
2. Upload the FIVE files from this folder to the repository root (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png).
3. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for GitHub to provide the HTTPS site address. Open it in iPhone Safari.
5. Safari Share > Add to Home Screen > Add.

No live AI connection, Moodle connection, push notifications, or server syncing yet. 16 synthetic cases. Progress stored on each browser. HTTPS required for service worker; offline mode works after first successful visit and cache installation.
